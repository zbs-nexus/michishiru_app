① 初期入力画面

入力項目

項目タイプ選択肢
目的ボタン選択気分転換/運動/観光/カフェ巡り
ジャンルボタン選択自然/街歩き/歴史/グルメ
距離スライダー1km/3km/5km/8km

処理内容

  1. ボタンクリックで選択状態を保存
  2. 選択ボタンの色を変更
  3. 「ルート作成」で次画面へ
  4. 未選択時はアラート表示

⚙️ server.js の処理

// Expressフレームワークを読み込み const express = require('express'); const app = express(); // publicフォルダを公開 app.use(express.static('public')); // サーバー起動（ポート3000） app.listen(3000, '0.0.0.0', () => { console.log('サーバー起動中'); });

const state = { purpose: null, // 選択された目的 genre: null, // 選択されたジャンル distance: 3, // 選択された距離（km） currentRoute: null // 現在のルート情報 };
