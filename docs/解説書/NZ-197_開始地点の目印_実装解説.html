NZ-197 開始地点の目印と現在地の矢印の削除 - 実装解説

📅 マージ日: 2026-09-30
🌿 ブランチ: feature/NZ-197（PR #54 / e2826da）
📝 課題番号: NZ-197

📖 この機能について

地図上の変更が2つあります。

  1. 開始地点の目印を追加: ルートの出発地（origin）に、緑の丸に「S」と書いたマーカーを立てます。押すと「スタート地点」と表示されます。
  2. 現在地の矢印を削除: 現在地マーカー（青い丸）に付いていた「向いている方向」の矢印をなくし、それを計算していたコードも消しました。

🎯 なぜこの機能が必要？

  • ミチシルの散歩は、スポットを回って出発地に戻ってくる形です。どこから出たかが地図で分からないと、帰り道の見当がつきません。
  • スポットのマーカー（青い丸に巡る順の番号）と同じ見た目だと区別できないため、色と文字を変えています。
  • 矢印の削除について、コミットには「方向矢印を削除し、未使用になった計算も除去する」とだけあり、詳しい理由は書かれていません。方向はブラウザから取れないことが多く、取れない場合は直前の位置との差から推測していたため、止まっているときや GPS が揺れたときに向きが不安定だった、というのが考えられる理由です（推測です。正確な理由は担当者に確認してください）。

🔄 処理の流れ

Step 1: 経路の先頭の座標を取り出す
ルートを作るとき、現在地を出発地として送っています。そのため、経路の形（geometry）の最初の点が開始地点になります。toOriginPosition がこれを取り出します。
Step 2: マーカーを立てる（または動かす）
renderOriginMarker が、まだマーカーがなければ作り、あれば位置だけ動かします。経路がないときはマーカーを消します。
Step 3: 描き直すタイミング
地図の読み込みが終わったとき（map.on('load')）と、経路が変わったとき（再作成など）に呼びます。画面を離れるときにはマーカーを片付けます。

💻 コードの解説

frontend/src/components/feature/route/RouteMap.vue — 開始地点の座標

const toOriginPosition = (geometry) => {
  const rawGeometry = geometry === null ? null : toRaw(geometry);
  const firstPosition = rawGeometry?.coordinates?.[0];

  if (!Array.isArray(firstPosition)) {
    return null;
  }

  const lng = Number(firstPosition[0]);
  const lat = Number(firstPosition[1]);
  // ...数値でなければ null
  return [lng, lat];
};
  • 入力: 経路の形（GeoJSON の LineString）。出力: [経度, 緯度] か null。
  • 座標は [経度, 緯度] の順です（地図ライブラリの決まり）。緯度が先ではないので注意してください。
  • toRaw は、Vue が監視用に包んだオブジェクトから中身を取り出す関数です。地図ライブラリに Vue の包みを渡さないためです。

RouteMap.vue — マーカーを描く

if (originMarker === null) {
  originMarker = new Marker({ element: createOriginMarkerElement() })
    .setLngLat(originPosition)
    .setPopup(new Popup({ offset: 16 }).setText(ORIGIN_POPUP_TEXT))
    .addTo(map);
  return;
}

// 再作成で別のルートに差し替わった場合は位置だけ更新する
originMarker.setLngLat(originPosition);

毎回作り直さず、2回目以降は位置だけを動かします。表示する文字は定数 ORIGIN_MARKER_LABEL（'S'）と ORIGIN_POPUP_TEXT（'スタート地点'）にまとめています。

frontend/src/assets/styles/global.css — .origin-marker

スポットのマーカーより一回り大きい 32px の緑の丸です。地図ライブラリはマーカーをコンポーネントの外側に挿入するので、<style scoped>（そのコンポーネントの中だけに効くスタイル）が届きません。そのため、スポットマーカーと同じく global.css に書いています。

矢印の削除で消えたもの

場所消えたもの
useLocationTracking.jsheading（向き）、calculateBearing（2点から向きを計算）、previousLocation（前回の位置）

使わなくなった値を親から子へ渡し続けると、読む人が「どこで使っているのか」と迷うので、受け渡しの途中まで全部消しています。

⚠️ 注意ポイント

開始地点は「経路の先頭」から取っている
バックエンドが経路の最初の点を出発地にしている、という前提に依存しています。将来「出発地を自由に選べる」ようにする場合などで経路の先頭が出発地でなくなったら、この取り方を見直す必要があります。
global.css のコメントが一部古い
現在地マーカーの説明に「青い円と方向を示す矢印で構成」というコメントが残っています。矢印はもうないので、次に触るときに直してください。

✅ 動作確認方法

  1. リポジトリのルートで npm run dev を実行します。
  2. ルートを作成し、提案画面の地図で、経路の端に緑の「S」マーカーが出ることを確認します。押すと「スタート地点」と出ます。
  3. 「再作成」を押して、S マーカーが新しい経路の開始位置に移ることを確認します（1つだけ表示され、増えないこと）。
  4. 案内画面へ進み、現在地の青い丸に矢印が付いていないことを確認します。
  5. frontend/ で npm run lint と npm run build を実行します（フロントの自動テストは未導入です）。
