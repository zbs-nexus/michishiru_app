ダブルタップでの拡大防止 - 実装解説

🗓 対象期間: 2026-10-21
📅 マージ日: 2026-10-21（12:51）
🌿 対象ブランチ: feature/NZ-306
🔖 対象マージ: 37fe610（ダブルタップでの画面拡大防止）
※ 同じブランチの 10ca729（フクロウ画像の追加）は マスコットのレベルアップ で扱います。

🧩 先に知っておきたいこと

スマートフォンのダブルタップ拡大
スマートフォンのブラウザは、画面を素早く2回たたくとページを拡大します。ボタンを素早く2回押したときにも起き、意図せず画面が拡大されて戻しにくくなります。
CSS の touch-action
その要素の上で、ブラウザにどのタッチ操作（スクロール・ピンチ・ダブルタップ拡大）を任せるかを指定するプロパティです。 manipulation は「スクロールとピンチは許可、ダブルタップ拡大だけ止める」指定です。
:where() と詳細度
CSS では、より具体的なセレクタの指定が勝ちます（詳細度）。:where(...) で囲んだ部分は詳細度が0になるので、各コンポーネントの個別の指定が必ず優先されます。

📖 この機能について

ボタン・リンク・入力欄などの操作部品の上でダブルタップしても、画面が拡大しないようにした変更です。 ピンチでの拡大は残しています。地図の中は対象外で、地図のダブルタップ拡大は従来どおり動きます。

🎯 なぜこの機能が必要？

案内画面では「次の目的地へ」や口コミの表示切り替えを歩きながら素早く押すため、2回押しで画面が拡大する誤操作が起きていました。 一方で、文字を大きくして読みたい人のためにピンチ拡大は止めてはいけません（アクセシビリティ）。そこでダブルタップ拡大だけを部品単位で止めています。

🔄 処理の流れ

Step 1: 共通ルール（global.css）
操作部品（button, a, label, summary, select, input, textarea, [role="button"]）に touch-action: manipulation を付けます。地図の中（.maplibregl-canvas-container の子孫）は除きます。
Step 2: ボタン以外の重なり部品にも個別に付ける
トースト（.toast）、次の目的地のバナー（.next-spot-banner）、口コミの表示切り替え（.review-toggles）、口コミフォーム（.review-form）、 ポップアップ（.popup）、下部のボタン置き場（.bottom-actions）にも同じ指定を足しています。部品のすき間をたたいても拡大しないようにするためです。

💻 コードの解説

frontend/src/assets/styles/global.css

:where(button, a, label, summary, select, input, textarea, [role="button"]):not(.maplibregl-canvas-container *) {
  touch-action: manipulation;
}
  • :where で詳細度を0にしているので、スワイプのために touch-action: none を持つ部品（写真の全画面表示・口コミフォームのハンドル）の指定が常に勝ちます
  • 地図の拡大縮小は MapLibre GL が自分で touch-action を設定して扱うため、上書きしません
  • index.html の viewport に user-scalable=no や maximum-scale は書きません。ページ全体の拡大が止まってしまい、iOS はそもそも無視するためです

⚠️ 注意ポイント

操作部品でない場所のダブルタップでは拡大が残る
見出しや本文など、対象に含めていない場所をダブルタップすると拡大することがあります（検証記録で既知の範囲外としている）。
新しい重なり部品を作るときは同じ指定を足す
ボタン以外の要素（div など）で作った浮いた部品は共通ルールの対象外です。トーストやバナーと同じく touch-action: manipulation を足してください。
自動テストでは実際の拡大は確かめられない
src/assets/styles/__tests__/global.test.js は CSS の宣言があるかどうかを確かめるだけです。実際の動きは実機（iPhone Safari / Android Chrome）で確認します。

✅ 動作確認方法

  1. スマートフォンから dev 環境（またはローカルを同じネットワークで公開したもの）を開く
  2. 案内画面で口コミの表示切り替え・「次の目的地へ」・「前の目的地へ」・終了ボタンを素早く2回押し、画面が拡大しないことを確かめる
  3. トーストや終了ボタン付近でピンチすると、従来どおり拡大できることを確かめる
  4. 地図のダブルタップ・ピンチ・ドラッグ・長押し、写真の全画面表示のスワイプ、距離スライダーが従来どおり動くことを確かめる
  5. テスト: frontend で npm test（src/assets/styles/__tests__/global.test.js）
